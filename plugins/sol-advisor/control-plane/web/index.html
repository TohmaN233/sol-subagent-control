LOCAL CONTROL PLANE

Sol Subagent Control

Define reusable Task Types, then pin exactly one Provider to each implementation or review Stage. Sol may select a Task Type, but cannot change its Provider bindings or fall back silently.

MASTER SWITCHES

Global controls

Loading

API keys are never stored here. OpenAI-compatible providers hold only an environment-variable name. Built-in Cursor/Grok and all external or paid providers are disabled in the bundled defaults; enabling a provider never calls it by itself.

MODEL AND TRANSPORT ADAPTERS

Providers

Native Providers expose Model and Reasoning effort as normal controls. Connector and web-review Providers inherit model settings from their own client; their local reasoning value remains empty and unsupported knobs are not shown.

WHEN TO USE WHAT

Task Types and stages

The plugin ships with ready-to-use, model-independent Task Types. Use them as-is, remove any you do not need, duplicate and remap their Stages to other Providers, add one again from the preset library, or start from a blank Task Type. Routes create a fixed Stage topology: solo has none, delegate has implementation, audit has review, and full has both.
